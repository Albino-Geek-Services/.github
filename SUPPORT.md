# Support

## Product / purchase support

Guides, power packs, pair-engineering sessions, and refunds are handled through the site — not GitHub issues.

→ [albinogeek.com](https://albinogeek.com/)

## Public repositories

When public OSS lands here:

- **Bugs / features:** open a GitHub issue on that repo
- **Security:** see [SECURITY.md](./SECURITY.md)
- **How to contribute:** see [CONTRIBUTING.md](./CONTRIBUTING.md)

## What GitHub issues are not for

- Booking pair-engineering hours
- Invoice or refund requests
- Access to private product repositories

Those go through the website contact path.
