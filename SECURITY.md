# Security

## Reporting a vulnerability

Do **not** open a public GitHub issue for security reports.

Email or brief the operator via [albinogeek.com](https://albinogeek.com/) with:

- Affected repo / component (if known)
- Description and impact
- Reproduction steps or proof-of-concept (private)

You should hear back within a few business days (Pacific). We do not run a bug bounty.

## Scope

Public repositories under [Albino-Geek-Services](https://github.com/Albino-Geek-Services). Private product systems are out of scope for unsolicited testing.

## Prefer responsible disclosure

Give us a reasonable window to patch before public write-ups. Credit is available on request after a fix ships.
